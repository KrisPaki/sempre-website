# Sempre Group, koncepcja strony

Statyczny mockup strony Sempre Group. Obejmuje markę główną Sempre oraz Cukieterię i Akademię WAPAS.

## Wersje

- `main`: aktualna wersja robocza.
- `backup-wersja-bazowa`: zachowany układ bazowy sprzed zmian roboczych.

## Podgląd

Otwórz `dist/index.html` w przeglądarce. Strona korzysta z lokalnych plików w `dist/assets` oraz odwołań do oficjalnych logotypów i Google Fonts.

Prywatny podgląd wersji roboczej: https://sempre-wersja-robocza.kristec.chatgpt.site

Prywatny podgląd wersji bazowej: https://sempre-koncepcja-2026.kristec.chatgpt.site

Zdjęcia ludzi są wizualizacjami. Formularz kontaktowy i newsletter przygotowują wiadomości w programie pocztowym; nie ma tu zaplecza do zbierania zgłoszeń.
